## Quickstart

> **Note on Gradle Wrapper**: To keep project templates lightweight and safe, binary distribution wrappers (`gradle/wrapper/gradle-wrapper.jar`) are not bundled in this template. Initialize the local wrapper once via:
> ```bash
> gradle wrapper
> ```

```bash
# Build debug APK
./gradlew assembleDebug

# Run unit tests
./gradlew test

# Run linter
./gradlew lint

# Check code formatting
./gradlew spotlessCheck
```
